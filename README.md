# המכלול אופליין - Hamichlol Offline

אפליקציית Electron המאפשרת התקנת והרצת MediaWiki באופן מקומי ללא צורך בחיבור לאינטרנט.

## מאפיינים

- שימוש ב-PHP, MariaDB/MySQL ו-MediaWiki שכבר מותקנים במחשב
- הורדה והתקנה אוטומטית של מה שחסר (PHP ו-MariaDB: ב-Windows בלבד)
- ממשק משתמש פשוט לניהול השרתים, ותפריט עברי מלא
- הוויקי מוצג בכל חלון האפליקציה, ומותקן בעברית
- הרצת המערכת ללא צורך בחיבור לאינטרנט

## דרישות מערכת

- Windows 10 ומעלה, או לינוקס / macOS עם PHP ו-MariaDB (או MySQL) מותקנים
- מינימום 500MB פנויים בדיסק
- מינימום 4GB RAM

## התקנה למפתחים

1. התקן את Node.js בגרסה 22.12 ומעלה (דרישה של Electron)
2. שבט (Clone) את המאגר:
```bash
git clone https://github.com/michi-tz/hamichlol-offline.git
cd hamichlol-offline
```

3. התקן את התלויות:
```bash
npm install
```

4. הרץ את האפליקציה:
```bash
npm start
```

## בנייה לשימוש

```bash
npm run dist
```

הקובץ המותקן יהיה זמין בתיקיית `dist`.

## ממשק המשתמש

לחלון יש שני מצבים:

- **מסך ההתקנה** (כשהשרתים כבויים): שלושה שלבים עם מחוון התקדמות - התקנת השרתים, הגדרת הוויקי והפעלה.
  בזמן פעולה ארוכה (הורדה, התקנה, הפעלה) מוצג מצב "עובד", ושגיאות מוצגות בנפרד משורת המצב הרגילה.
  אחרי הפעלה מחדש של האפליקציה המסך ממשיך מהשלב שבו עצר.
- **מצב ויקי** (כשהשרתים פועלים): הוויקי ממלא את כל החלון. מעליו נשאר רק סרגל דק עם ניווט
  (אחורה, קדימה, רענון, עמוד ראשי), נורית "השרתים פועלים", פתיחה בדפדפן חיצוני וכפתור לעצירת השרתים.
  אם השרתים נעצרים מעצמם, החלון חוזר למסך ההתקנה ומציג הודעה.

הוויקי מוצג ב-`WebContentsView` נפרד (ולא ב-`iframe` בתוך דף האפליקציה): בלי גישה ל-Node, בארגז חול (sandbox),
עם עוגיות נפרדות, ובלי הרשאות (מצלמה, מיקום וכו'). כך גם דפי העריכה של MediaWiki, שאסור להציג במסגרת, עובדים.
רק כתובות של הוויקי המקומי (`127.0.0.1` / `localhost` בפורט של PHP) נפתחות בתוך האפליקציה;
קישורים לאתרים אחרים, וגם קישורים שמבקשים חלון חדש, נפתחים בדפדפן של המערכת.

התפריט:

| תפריט | פקודות |
|-------|--------|
| שרתים | הפעל שרתים, עצור שרתים, הפעל מחדש, יציאה (כל פקודה זמינה רק כשאפשר לבצע אותה) |
| ויקי | עמוד ראשי, אחורה, קדימה, רענון, פתח בדפדפן חיצוני (זמין רק כשהוויקי מוצג) |
| סנכרון | מקום שמור לסנכרון עם אתר המכלול, שעדיין לא קיים |
| תצוגה | הגדלה, הקטנה וגודל רגיל (של הוויקי כשהוא מוצג), מסך מלא, כלי פיתוח |
| עריכה | ביטול, ביצוע שוב, גזירה, העתקה, הדבקה, בחירת הכול |
| עזרה | אודות, פתיחת תיקיית הנתונים |

הכפתורים בחלון והפקודות בתפריט מפעילים את אותו קוד בתהליך הראשי, ולכן תמיד מסונכרנים.

## הגדרת הוויקי

הוויקי מותקן בעברית (`install.php --lang=he`, כלומר `$wgLanguageCode = "he"`). ויקי שכבר הותקן בעבר אינו משתנה.

שם המשתמש והסיסמה של המנהל נבדקים כבר בטופס, תוך כדי הקלדה, לפי אותם כללים ש-MediaWiki 1.43
מחיל על מנהלים (`$wgPasswordPolicy` לקבוצות sysop, ‏bureaucrat ו-interface-admin) - כך שתוכנית ההתקנה
לא נכשלת באמצע, אחרי שמסד הנתונים כבר נוצר:

- לפחות 10 תווים ועד 4096. האורך נמדד בבתים, כמו ב-MediaWiki, ולכן אות עברית נספרת כשניים
- הסיסמה אינה מוכלת בשם המשתמש (בלי הבדל בין אותיות גדולות לקטנות)
- הסיסמה אינה אחת מסיסמאות הדוגמה ש-MediaWiki חוסם (למשל `ExamplePassword`)
- הסיסמה אינה ברשימת הסיסמאות הנפוצות של MediaWiki (הספרייה `wikimedia/common-passwords`, שנקראת מתיקיית
  `vendor` של ה-MediaWiki שהורד; אם הקובץ חסר או בפורמט לא מוכר, רק הבדיקה הזו מדולגת)
- שם המשתמש תקין: בלי התווים `# < > [ ] | { } / @ : =`, לא כתובת IP, לא שם שמור, לא ארוך מדי.
  האות הראשונה של השם הופכת לגדולה, וקו תחתון הופך לרווח - הטופס מציג איך השם יישמר

אם בכל זאת תוכנית ההתקנה נכשלת, מוצגת הודעה עם פרטי השגיאה (בלי הסיסמאות), ואפשר לתקן את הטופס ולנסות שוב:
מסד הנתונים של הניסיון הקודם נמחק ונוצר מחדש.

## שימוש בתוכנות שכבר מותקנות במחשב

לפני הורדה, האפליקציה מחפשת במחשב PHP, שרת מסד נתונים (MariaDB או MySQL) ו-MediaWiki.
מה שנמצא ומתאים משמש כמות שהוא, ורק מה שחסר יורד. שלב 1 בממשק מציג מה נמצא ומאיפה.

| רכיב | דרישות | מה נעשה איתו |
|------|--------|---------------|
| PHP | גרסה 8.3 בלבד (CLI) עם ההרחבות mysqli, intl, mbstring, fileinfo, openssl, xml, xmlreader, dom, ctype, iconv, json | מורץ ישירות, עם קובץ ה-`php.ini` שלו |
| MariaDB / MySQL | MariaDB 10.3 ומעלה (כולל `mariadb-install-db`) או MySQL 5.7.6 ומעלה | רק התוכנה משותפת: האפליקציה מריצה תהליך משלה, בפורט משלה ועם תיקיית נתונים משלה. שרת שכבר פועל במחשב והנתונים שלו אינם מושפעים |
| MediaWiki | גרסה 1.39 ומעלה | מועתק לתיקיית הנתונים של האפליקציה, בלי `LocalSettings.php`, ‏`images` ו-`cache`. ההתקנה הקיימת אינה משתנה |

החיפוש נעשה ב-`PATH` ובתיקיות התקנה נפוצות (למשל XAMPP, WampServer, Laragon ו-`Program Files` ב-Windows;‏ `/usr/bin`, ‏`/usr/sbin`, ‏`/usr/share/mediawiki` ו-Homebrew במערכות אחרות).
רכיב שהאפליקציה כבר הורידה בעבר ממשיך לשמש גם אם הותקנה בינתיים גרסה במחשב.

משתני סביבה:

| משתנה | תפקיד |
|-------|-------|
| `HAMICHLOL_PHP` | נתיב מלא לקובץ ההרצה של PHP |
| `HAMICHLOL_MYSQLD` | נתיב מלא ל-`mariadbd` / `mysqld` |
| `HAMICHLOL_MEDIAWIKI_DIR` | תיקיית MediaWiki קיימת |
| `HAMICHLOL_USE_SYSTEM=false` | לא להשתמש בתוכנות מותקנות, תמיד להוריד |

הורדה אוטומטית של PHP ו-MariaDB קיימת רק ל-Windows. בלינוקס וב-macOS צריך להתקין אותם מראש,
למשל באובונטו:

```bash
sudo apt install php-cli php-mysql php-intl php-mbstring php-xml mariadb-server
```

שימו לב: אם מסד הנתונים נוצר עם שרת בגרסה אחת, ובהמשך השרת המותקן במחשב מוחלף בגרסה ישנה יותר,
ייתכן שהשרת לא יצליח לפתוח את הנתונים.

## היכן נשמרים הנתונים

השרתים, קבצי MediaWiki ומסד הנתונים נשמרים בתיקיית נתוני המשתמש של האפליקציה
(`%APPDATA%\hamichlol-offline\data` בחלונות), ולא בתיקיית ההתקנה, שבדרך כלל אינה ניתנת לכתיבה.
אפשר לשנות את המיקום באמצעות משתנה הסביבה `HAMICHLOL_DATA_DIR`.

```
data/
├── server/
│   ├── php-<גרסה>/        # PHP
│   └── mariadb-<גרסה>/    # MariaDB
├── database/              # קבצי מסד הנתונים (נפרד מהגרסה של MariaDB)
├── mediawiki/             # MediaWiki ו-LocalSettings.php
└── run-state.json         # תהליכי השרתים שרצים כרגע
```

השרתים מאזינים רק לכתובת `127.0.0.1`. הפורטים נבחרים מחדש בכל הפעלה,
ו-`LocalSettings.php` מותאם כך שימשיך לעבוד גם אם הפורטים משתנים.

כשהאפליקציה נפתחת מחדש היא ממשיכה מהשלב שבו עצרה. אם בהפעלה קודמת היא קרסה
והשאירה שרתים פועלים, הם נעצרים אוטומטית.

## גרסאות ועדכוני אבטחה

הגרסאות וקישורי ההורדה מוגדרים בקובץ אחד: `src/versions.js`.
כרגע: PHP 8.3, ‏MariaDB 11.8 LTS, ‏MediaWiki 1.43 LTS.

גרסת ה-PHP צמודה לענף שוויקימדיה מריצה באתרים שלה, כדי שהוויקי ירוץ על אותו PHP שהקוד של מדיה־ויקי
נבדק עליו בפועל. לכן PHP שמותקן במחשב משמש רק אם הוא מאותו ענף (כרגע 8.3); גרסה ישנה או חדשה יותר
לא תשמש, וב-Windows תורד במקומה הגרסה המתאימה. כשוויקימדיה עוברת לענף חדש, מעדכנים את `PHP_VERSION`.

לעדכון גרסה: משנים את מספר הגרסה בקובץ ובודקים שהקישורים זמינים:

```bash
npm run check-downloads
```

PHP ו-MariaDB מותקנים בתיקיות לפי גרסה, כך שגרסה חדשה תורד בהפעלה הבאה
לצד הישנה, ומסד הנתונים נשמר. עדכון גרסת MediaWiki עבור ויקי שכבר מותקן
עדיין לא נתמך (דורש הרצה של `update.php`).

## בדיקות

יש שלוש רמות של בדיקות. כולן עובדות בתיקיות זמניות ואינן נוגעות בנתונים של האפליקציה או במסד נתונים שמותקן במחשב.

| פקודה | מה נבדק | מה נדרש |
|-------|---------|---------|
| `npm test` | הלוגיקה כולה: מצב פיתוח, מסלול ההתקנה וההפעלה האמיתי מול תוכנות דמה, הורדות מול שרת מקומי, איתור תוכנות מותקנות, בדיקות שם המשתמש והסיסמה של המנהל, התפריט, התהליך הראשי של Electron ותצוגת הוויקי | Node.js בלבד |
| `npm run test:system` | המסלול המלא מול PHP, ‏MariaDB/MySQL ו-MediaWiki אמיתיים שמותקנים במחשב, כולל כניסה לוויקי והתאוששות מקריסה | התוכנות מותקנות (אחרת הבדיקה מדולגת) |
| `npm run test:e2e` | חלון האפליקציה עצמו, דרך Playwright, במצב פיתוח: השלבים, הטופס, התפריט, והוויקי שממלא את החלון | תצוגה (בלינוקס בלי מסך: `xvfb-run -a npm run test:e2e`) |

`npm run test:all` מריץ את שלושתן, ו-`npm run coverage` מפיק דוח כיסוי בתיקיית `coverage`.

ב-`npm test` שום דבר לא יורד מהאינטרנט ושום שרת אמיתי לא רץ: במקום PHP ו-MariaDB רצות תוכנות דמה
(`test/fixtures`), ותוכנת הדמה של מסד הנתונים מדברת בפרוטוקול של MySQL, כך שהחיבור, שאילתות ההקמה
והכיבוי של האפליקציה נבדקים באמת. חלק מהבדיקות האלה מדולגות ב-Windows, שם אי אפשר להריץ את תוכנות הדמה.

להרצת `test:system` באובונטו:

```bash
sudo apt install php-cli php-mysql php-intl php-mbstring php-xml mariadb-server mediawiki
```

ב-GitHub Actions‏ (`.github/workflows/test.yml`) רצות הבדיקות הרגילות בלינוקס, ב-Windows וב-macOS,
ובנוסף בדיקות המערכת וחלון האפליקציה באובונטו.

## מבנה הפרויקט

```
hamichlol-offline/
├── src/                    # קוד המקור של האפליקציה
│   ├── main.js             # תהליך ראשי של Electron: חלון, פעולות, סנכרון המצב
│   ├── menu.js             # התפריט העברי
│   ├── wiki-view.js        # תצוגת הוויקי (WebContentsView) וחסימת ניווט החוצה
│   ├── admin-validation.js # בדיקת שם המשתמש והסיסמה של המנהל לפי כללי MediaWiki
│   ├── server-manager.js   # ניהול התקנה והפעלת שרתים
│   ├── system-tools.js     # איתור תוכנות שכבר מותקנות במחשב
│   ├── versions.js         # גרסאות וקישורי הורדה
│   └── renderer/           # קבצי ממשק משתמש
│       └── index.html      # מסך ההתקנה והסרגל שמעל הוויקי
├── test/                   # בדיקות
│   ├── fixtures/           # תוכנות דמה של PHP ומסד הנתונים
│   ├── system/             # בדיקות מול תוכנות אמיתיות (npm run test:system)
│   └── e2e/                # בדיקות של חלון האפליקציה (npm run test:e2e)
├── scripts/                # סקריפטים לאוטומציה
└── package.json            # הגדרות פרויקט, תלויות ותצורת electron-builder
```
